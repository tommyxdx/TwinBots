# 模拟成交的含义

## CEX 生命周期

信号使用已结束 K 线 → 检查现金、库存、交易过滤器 → 写入唯一订单 ID → 等待设定网络/处理延迟 → 读取到达时同步订单簿 → 按价格限制逐档成交 → 原子提交账本与结果。

- 只支持限价 IOC，不模拟 maker 排队。因此没有“碰到限价就成交”的逻辑。
- 成交量受每档可见量 × `visible_liquidity_fraction` 限制。相同更新序列内已被虚拟订单消费的深度不会重复使用；该价格被真实市场更新后可重新供给。
- 压力成交价增加/减少 `adverse_fill_bps`，且仍须满足最初限价。超出已知深度不继续假设有流动性。
- 网络延迟从 `[250,750]ms` 均匀抽样是**未校准假设**；WebSocket 事件时间用于过期检查。延迟包含在真实运行等待中，不是只从收益减一个比例。
- 量价步长用 Decimal 量化；处理 LOT_SIZE、PRICE_FILTER、MIN_NOTIONAL/NOTIONAL。存在动态价格过滤器时查 `/avgPrice` 并核对窗口；不能核对则拒绝该模拟订单。当前不覆盖交易所所有特殊限制、账户权限及临时风控；参考价格到模拟到达期间也可能变化。
- 费用默认每边 0.1%，可查询账户的 taker、buyer/seller、tax、special commission；BNB 折扣未应用。以报价币等值扣费，与实际资产扣费造成的 dust 可能不同。
- 1% 丢失回执是假设。实际本地结算与账本同一事务提交，外层状态记 UNKNOWN，核对前不重复下单。重启恢复已有结算；未结算 SUBMITTED 记 CANCELED_RESTART。**这是 paper 的恢复语义，不能直接移植成实盘的“断线即撤单”。**
- 市场因虚拟订单而变化的冲击无法反馈到真实市场；深度折扣是压力假设，不能替代真实冲击估计。
- CEX 日常净值用最佳买价减卖出费估值，不逐仓消耗整本深度，因此实际退出可能更差。断线保留最近估值并标记 stale，暂停受影响退出与新入场；损失不会被这个旧估值限制。
- 止损是条件触发的 IOC 尝试，最多每币每 30 秒重试；订单仍可部分成交/失败。小额尾仓低于最小名义金额时保留在库存。10% 回撤阈值不是保本保证。

## DEX 生命周期

查询买卖双方路由/往返成本 → 记录初始 `min_out` → 等待延迟 → 取新报价 → 施加输出压力 → 成功、未上链丢弃、模拟回滚或无法验证。

1. `outAmount` 已包括路由 AMM/平台手续费，不再重复扣一次 AMM 费；另扣配置的 gas 和额外费。
2. 掉单概率和回滚概率是明确标注的假设。掉单在上链前发生，gas 为 0；模拟已包含但回滚扣 gas。第二次报价失败只说明无法验证，不捏造链上回滚或 gas。
3. 一笔 swap 的虚拟库存变化是原子的；失败不会得到半份币。输入输出均为原始整数单位，虚拟持仓可用于下一次反向报价。
4. 只读 quote 不需要钱包持仓，却也不能证明某个钱包能通过所有 token 检查。`simulateTransaction` 不广播，但普通 RPC 不会替 paper 保留虚拟买入余额；本项目没有假称实现完整的跨交易链上状态分叉。
5. Jupiter 的本地响应时间不等于独立验证的区块新鲜度；报告保留 context slot。对 MEV、验证者拥堵、优先费竞争、被拉走的流动性、代币转账钩子/税/黑名单，报价压力只能近似，不能声称高度保真。
6. USDC 默认按 $1 计，gas 按美元从虚拟现金扣，不模拟真实钱包 SOL 余额与脱锚。若比较其它链，务必修改报价币、精度、手续费和延迟假设。
7. 无反向报价的持仓超过 `stale_mark_s` 后按 0 估值，数量仍在账本内。若接口恢复可继续退出；账户回撤触发的新仓暂停不会因报价恢复自动清除。

## 如何看待收益

历史 K 线用于训练与特征提取，**只有运行后的实时 paper 成交产生账户收益**。这避免把无法重建的历史盘口包装成真实成交回测。报告中的 realized_pnl、现金、手续费、库存、最新净值、UNKNOWN/失败/部分成交均可核对。

默认模型/扫描策略未证明有正期望。至少对比独立配置目录中的规则策略和模型策略，在相同时间运行，费用/延迟/深度假设一致；再用更差执行假设复测，观察净收益、回撤、成交率、失败率、未卖库存及费用占比。API 订阅、机器成本和人工时间应另行计入，不包含在账户损益内。不要把离线 demo、分类准确率或百倍图表目标当成能兑现的收益。
